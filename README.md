# 🚀 Noorado - Modern IT Consulting Website

### 🔗 Live demo: **http://localhost:5174/**

A modern, futuristic IT consultant services website built with **React + Vite + TypeScript + Tailwind CSS + Framer Motion**.

## ✨ Features

### 🎨 Design & UI
- **Modern Futuristic Aesthetic** - Black background with vibrant orange (#FF6B35, #FF8500) accents
- **Glassmorphism Effects** - Frosted glass cards with backdrop blur
- **Smooth Animations** - Powered by Framer Motion for scroll reveals and interactions
- **Responsive Design** - Mobile-first approach, works seamlessly on all devices
- **Custom Gradient Text** - Eye-catching orange gradient typography

### 📱 Sections

1. **Hero Section**
   - Animated background with gradient orbs and grid pattern
   - Compelling headline with call-to-action buttons
   - Real-time statistics display
   - 5-star rating showcase

2. **Services Section**
   - 8 core IT consulting services with icons
   - Interactive hover effects with glow animations
   - Services include:
     - Cloud Computing
     - Cybersecurity
     - Digital Transformation
     - AI & Machine Learning
     - DevOps & Automation
     - Data Analytics
     - Legacy Modernization
     - IT Strategy Consulting

3. **Portfolio Section**
   - Interactive carousel showcasing case studies
   - 5 featured projects with metrics and tags
   - Gradient headers with category indicators
   - Navigation controls with dots indicator

4. **About Section**
   - Company mission and values
   - Animated globe visualization
   - 4 core values with icons
   - Key statistics display

5. **Contact Section**
   - Modern contact form with validation
   - Contact information cards
   - Glass-morphic design elements

6. **Footer**
   - Multi-column layout with links
   - Social media integration
   - Newsletter signup
   - Scroll-to-top button

### 🎯 UX Best Practices

- **Sticky Header** - Transparent on top, solid on scroll with blur effect
- **Smooth Scroll** - All anchor links scroll smoothly
- **Mobile Menu** - Hamburger menu with slide-in animation
- **Accessibility** - ARIA labels, semantic HTML, keyboard navigation
- **Performance** - Optimized animations, lazy loading, efficient rendering
- **Custom Scrollbar** - Orange-themed scrollbar matching brand colors

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🎨 Theme & Branding

### Color Palette
- **Primary Orange**: `#FF6B35` (brand-orange)
- **Secondary Orange**: `#FF8500` (brand-orange-dark)
- **Background**: `#000000` (black)
- **Text**: `#FFFFFF` (white)

### Typography
- **Headings**: Space Grotesk (Bold, 400-700)
- **Body**: Inter (Regular, 300-800)
